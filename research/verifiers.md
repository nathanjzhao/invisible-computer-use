C = confirmed in linked source; I = inferred recommendation; U = not established.

- **C — OSWorld:** `evaluation_examples/examples/<app>/<id>.json`: setup `config`; `evaluator.{func,result,expected,options,conj,postconfig}`. Getters include `vm_file`, `vm_command_line`, cloud references, app preferences and browser SQLite/DOM state; metrics compare text, documents, tables, images and rules. `postconfig` runs before grading—potentially saving/reopening apps. [Schema/implementation](https://github.com/xlang-ai/OSWorld/blob/main/desktop_env/desktop_env_pointer.py), [getters](https://github.com/xlang-ai/OSWorld/tree/main/desktop_env/evaluators/getters), [metrics](https://github.com/xlang-ai/OSWorld/tree/main/desktop_env/evaluators/metrics).
- **C — OSWorld-Verified:** In-place upgrade, retaining this format; repairs graders, stale tasks and infrastructure. Adds document tolerance, perceptual image comparison and spreadsheet semantics. “Verified” concerns benchmark reliability, not input-driver isolation. [Report](https://xlang.ai/blog/osworld-verified).
- **C — Windows Agent Arena:** JSON `id/instruction/config/evaluator/result`; getter/rule/metric pattern. Checks files, settings and golden-image similarity, with binary or continuous rewards. Win32/UIA accessibility supports observations; that alone is not an accessibility-based grader. [Paper, §§A.3/A.6](https://arxiv.org/html/2409.08264v1).
- **C — AndroidWorld:** Python `TaskEval` subclasses: randomized parameters, `initialize_task`, `is_successful`, `tear_down`. ADB checks filesystem, SQLite rows, settings and UI hierarchy; composite tasks receive partial credit. [Design/examples](https://arxiv.org/html/2405.14573v1#S3).
- **C — WebArena:** JSON `eval.eval_types`: `string_match`, `url_match`, `program_html`; references specify answers, URLs, locators and required contents. Checks DOM/JS-derived app state; answer fuzzy matching invokes an LLM. [Evaluator](https://github.com/web-arena-x/webarena/blob/main/evaluation_harness/evaluators.py).
- **C — ScreenSpot/Pro:** Screenshot, instruction and target bounding-box records; point-in-box grounding accuracy, not executed-click success. Pro normalizes pixel boxes using `img_size`. [ScreenSpot data](https://huggingface.co/datasets/bevaya/ScreenSpot), [Pro evaluator](https://github.com/likaixin2000/ScreenSpot-Pro-GUI-Grounding/blob/main/eval_screenspot_pro.py).
- **C — AgentNetBench:** Offline JSON trajectories: `steps[].image/ground_truth_actions`; actions contain `type/params/metadata.bboxes`. Scores coordinates/bboxes, text edit distance, normalized keys, scroll direction/amount and extra-action penalties. [Schema](https://github.com/xlang-ai/OpenCUA/blob/main/evaluation/agentnetbench/README.md).
- **C — macOSWorld:** JSON multilingual `task/snapshot`, `pre_command`, delays and weighted `grading_command` entries; shell/AppleScript checks. Concrete grader reads `System Events` accessibility `AXChildren`. [Example](https://github.com/showlab/macosworld/blob/master/tasks/sys_apps/07709761-78b1-8043-ffb2-eebaeed08109.json).

- **C — Input suites:** [xdotool](https://github.com/jordansissel/xdotool/tree/main/t) uses Ruby/Minitest, Xvfb/Xephyr, window/pointer checks and `xterm` running `cat` into a file as typing oracle. [PyAutoGUI](https://github.com/asweigart/pyautogui/blob/master/tests/test_pyautogui.py) checks positions and terminal `input()` echo; most click functionality remains untested.
- **C — nut.js/RobotJS:** [nut.js](https://github.com/nut-tree/nut.js/tree/develop/e2e/window-test) has an Electron sample-window integration suite using Jest/Playwright. [RobotJS keyboard tests](https://github.com/octalmage/robotjs/blob/master/test/keyboard.js) largely assert no exception, explicitly acknowledging missing delivery verification.
- **C — Browser conformance:** [Playwright](https://github.com/microsoft/playwright/blob/main/tests/page/page-keyboard.spec.ts) uses textarea/input fixtures and DOM event arrays. [WebDriver WPT](https://github.com/web-platform-tests/wpt/tree/master/webdriver/tests/classic/perform_actions) uses `test_actions.html`, `#keys`, event recording, pointer/wheel fixtures and release cleanup.
- **C/U — AutoHotkey:** [KeyHistory](https://github.com/AutoHotkey/AutoHotkeyDocs/blob/v2/docs/lib/KeyHistory.htm) records keyboard/button events with hooks; a comprehensive upstream injection-conformance suite was not established.

- **C — macOS monitoring:** [`NSWorkspace.frontmostApplication`](https://developer.apple.com/documentation/appkit/nsworkspace/frontmostapplication), activation notifications, [`CGEvent.location`](https://developer.apple.com/documentation/coregraphics/cgevent/location). **I:** additionally inspect focused window/control; app identity alone misses same-app focus changes.
- **C — Windows:** [`GetForegroundWindow`](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getforegroundwindow), [`GetCursorPos`](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getcursorpos), [`GetGUIThreadInfo`](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getguithreadinfo) expose foreground, pointer, focus/capture/caret state.
- **C — Linux:** X11 [`_NET_ACTIVE_WINDOW`](https://specifications.freedesktop.org/wm/1.5/ar01s03.html), [`XQueryPointer`](https://www.x.org/releases/current/doc/libX11/libX11/libX11.pdf). [Wayland](https://wayland.freedesktop.org/docs/html/apa.html) exposes surface-local events, no portable global equivalent. **I:** use compositor instrumentation; supplement polling with events to catch transient theft.

- **C/U — Hosted CI:** macOS runners have supported [emulated displays](https://github.com/actions/runner-images/discussions/5730), but [AX failures occur](https://github.com/actions/runner-images/issues/11874). Windows GUI CI has [Microsoft examples](https://github.com/microsoft/winappCli/blob/main/docs/ui-automation.md); `windows-latest` alone does not establish every injection/capture prerequisite. **I:** preflight desktop access and permissions.
- **C/I — Controlled CI:** Linux [Xvfb/Xephyr](https://github.com/jordansissel/xdotool/blob/main/t/ephemeral-x.sh); self-hosted Mac minis with [Tart](https://github.com/openai/tart)/[Lume](https://cua.ai/docs/how-to-guides/lume/install-lume); Windows [QEMU/KVM](https://arxiv.org/html/2409.08264v1)/[Hyper-V](https://learn.microsoft.com/en-us/windows-server/virtualization/hyper-v/get-started/create-a-virtual-machine-in-hyper-v), maintaining interactive login. Record via [FFmpeg](https://ffmpeg.org/ffmpeg-devices.html): `avfoundation`, `gdigrab`, `x11grab`; retain timestamped logs.

Recommended verifier taxonomy — **I**, proposed:

- Delivery: native receiver logs target window/control, coordinates, keys, modifiers and sequence.
- Focus preservation: foreground/focused-control event timeline, including transient changes.
- Cursor preservation: independent pointer trace; reject move-and-restore excursions.
- Capture fidelity: animated nonce/checkerboard under occlusion; detect stale, black or occluder pixels.
- Semantic UI state: accessibility/DOM values, selection, focus and enabled state.
- Persistent state: files, parsed documents, settings and DB queries.
- End-to-end outcomes: fresh snapshots, independent graders, repeated trials and negative controls.
- Judgment: constrained LLM/human review for ambiguous outcomes, separately reported.
