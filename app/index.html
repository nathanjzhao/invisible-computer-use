      Keep a local record of allowed app activity. App identity is the default. On macOS, Windows and Linux, you can separately approve focused control labels and text values. Password fields are excluded. Browser capture needs its own opt-in below.

      Focused control scopes require Accessibility access and keep labels and values in local activity records. App and website context can feed enabled memory summaries. These scopes exclude images, audio and individual keystrokes.
      
          
      Native interactions additionally record clicks, shortcuts, typed text and accessible text in the current native window. On macOS this scope needs Input Monitoring. On Windows and Linux text is captured as observed field values. Linux support depends on the desktop session. Supported Wayland integrations observe scoped native interactions; unavailable observations remain marked incomplete. Browser and embedded web content are excluded. It uses the same History rules, pause and deletion controls. Images and audio are excluded.

Private windows, unverified pages and browser toolbars are excluded. Website rules apply before content is saved.
